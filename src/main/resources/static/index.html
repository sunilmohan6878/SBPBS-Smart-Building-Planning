ABOUT SBPBS

Smart planning for better decisions

What is SBPBS?

The Smart Building Planning and Blueprint Suggestion System is a preliminary planning and decision-support platform. It accepts site and building requirements, performs rule-based analysis and produces recommendations along with a preliminary 2D layout.

The system is designed as an academic software engineering prototype demonstrating frontend development, Java backend integration, database management, analysis logic and visualization.

Technology Stack

HTML CSS JavaScript Java Spring Boot REST API MySQL JUnit

Problem

Preliminary building planning often requires combining several site and building parameters manually.

Objective

Provide a simple digital platform for preliminary planning, recommendations and visualization.

Future Scope

Backend persistence, advanced optimization, professional verification workflows and improved planning intelligence.

Important: SBPBS provides preliminary academic planning suggestions only. The generated visualization is not a structural or architectural approval drawing. Professional civil/architectural verification is required before construction.
